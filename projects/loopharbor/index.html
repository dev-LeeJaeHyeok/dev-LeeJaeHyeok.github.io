LoopHarbor (AI Assistant)

역할
개인 프로젝트
기술
  • Java
  • Spring Boot · Spring AI
  • PostgreSQL (pgvector)

이 프로젝트는

Slack으로 받은 업무를 내 방식과 회사 규칙대로 처리하고, 내가 승인한 뒤에만 결과를 내보내는 개인 업무 어시스턴트입니다.
개발자, 디자이너, 기획자를 대상으로 Slack, GitHub, 로컬 프로젝트를 연결해 업무를 분석하고 수정하고 검증한 뒤, 사용자 확인을 거쳐 PR 생성과 요청자 회신까지 수행합니다.

문제와 해결

문제

  • 현업 업무가 Slack 멘션으로 흩어져 들어오고, 요청마다 맥락 파악, 자료 확인, 작업, 답장을 사람이 반복
  • 범용 AI는 회사의 맥락을 모르고, 요청할 때마다 다르게 받아들임
  • 결과를 검증 없이 바로 내보낼 위험

해결

Slack, GitHub, 로컬 프로젝트를 연결해 받은 업무를 사용자의 방식대로 분석, 수정, 검증하고, 사용자 확인을 거쳐 PR 생성과 요청자 회신까지 안전하게 수행하도록 만들었습니다.

주요 기능

업무 수신부터 검토까지

업무 수신과 계획

허용한 채널에서 나를 멘션한 업무를 즉시 받아 대화를 분석하고, 업무별 단계와 필요한 도구, 결과물을 담은 실행 계획 카드로 제시합니다.

도구 기반 에이전트

목표에 맞게 아래 도구를 조합해 업무를 처리합니다.

  • 웹 검색과 웹 페이지 읽기
  • GitHub 저장소 읽기와 수정
  • 로컬 문서(PDF, Word, Excel) 읽기와 사내 문서 검색
  • 개발 서버 실행
  • Figma, Notion, Jira 연동

검토 루프

결과를 승인한 계획, 확인한 근거, 나의 작성 규칙과 대조해 만족할 때까지 최대 3회 재작업합니다.

업무 유형별 처리

개발 업무

독립된 작업본에서 수정하고, 프로젝트별 검증을 격리된 실행 환경에서 수행한 뒤 변경 내용을 검토합니다. 이후 새 브랜치, commit, Draft PR까지 만들며, 기존 회사 CI/CD와 충돌하지 않도록 선택적으로 연동합니다.

디자인·기획 업무

Figma 시안 초안 작성, 기획 문서와 일정 정리를 각 도구에서 직접 수행합니다.

내 방식 학습과 운영

내 방식 학습

초반과 업무 중 인터뷰로 사용자 프로필과 회사 규칙(코딩 규칙, 커밋·PR 컨벤션, 문서 말투)을 만들고 버전을 관리합니다. 계획, 실행, 검토가 모두 같은 기억을 참조해 매번 같은 기준으로 처리합니다.

답장

요청자에게 보낼 답장(개조식)과 확인 과정을 분리해 보여주고, 승인한 답장만 원래 스레드에 게시합니다. 원하면 업무 유형별 자동 전달도 선택할 수 있습니다.

개선 제안

공식 문서와 변경 이력을 출처와 함께 모아 업무 방식 개선안을 제안하고, 승인한 것만 반영합니다.

Slack 홈 탭

시작 대기, 진행 중, 완료 업무와 실행 중인 개발 서버를 한 화면에서 관리합니다.

기술 스택

언어·프레임워크Java 25, Spring Boot 4.1, Gradle 9

에이전트 루프

  • Spring AI ChatClient의 도구 호출 루프 위에 비용 예약, 중단, 비밀정보 차단, 호출 상한을 Advisor로 결합
  • 계획은 Haiku, 실행과 검토는 Sonnet으로 모델 역할을 분담
  • MCP로 Figma, Notion, Jira 등 외부 도구를 서비스별 승인 후 연결

사내 문서 검색

  • PostgreSQL의 pgvector 기반으로 사내 문서를 색인하고 검색(RAG)
  • Flyway로 스키마 변경을 관리

안전장치

  • 원본 반영, PR, 요청자 전달은 코드로 고정된 승인 절차로만 실행
  • 승인은 변경 내용과 검증 결과에 묶여, 내용이 바뀌면 무효
  • 자료나 메시지 안에 들어 있는 지시는 권한으로 취급하지 않음
  • 키와 토큰은 로그와 AI 입력에서 차단

리서치와 검증

정해진 행동 선택에서 도구 조합 에이전트로 전환

초기에는 AI가 정해진 행동 중 하나를 고르는 구조였습니다. 이 구조는 읽기 전용 질문을 수정 작업으로 잘못 보내 실패하는 문제가 있음을 확인했고, 도구를 조합해 처리하는 에이전트 구조로 전환했습니다.

Spring AI 도구 루프 채택 검증

Spring AI 도구 루프 안에서 호출별 비용 예약, 중단, 웹 검색을 함께 지킬 수 있는지 먼저 검증한 뒤 채택했습니다.

결과

  • 비공개 저장소에 Draft PR을 생성하는 흐름을 끝까지 검증
