개요

약 300개 고객사가 이용하는 B2B 플랫폼으로, 월평균 9천만 건의 SMS, LMS, MMS, RCS, 알림톡을 처리하는 서비스입니다. 20년간 운영되어 온 레거시 시스템을 전면 개편하는 프로젝트로, C, Java, Python으로 나뉘어 운영되던 시스템을 Java와 Spring Cloud 기반의 MSA 재설계와 백엔드 서버 개발과 CI/CD 파이프라인을 구축 했습니다.

Spring Cloud 기반의 시스템 통합으로 개발 및 유지보수 비용 절감

문제

20년간 운영되어 온 기존 플랫폼은 SMS, LMS/MMS, RCS, 알림톡 서비스마다 개발 언어와 환경이 달라, 공통 기능도 각 환경에 맞춰 따로 개발해야 했고, 환경마다 개별적으로 운영해야 됐기 때문에 유지보수와 운영에 많은 비용이 발생했습니다.

해결

개발과 운영 비용 문제를 해결하기 위해서 레거시 시스템을 하나의 플랫폼으로 통합했습니다.

먼저 각 서비스의 기획 문서와 코드를 분석해 공통 기능과 서비스별 고유 기능을 분류하고, 필요한 서비스만 독립적으로 개발하고 배포할 수 있도록 기능적 응집도를 고려한 MSA 서버 아키텍처를 설계했습니다.
